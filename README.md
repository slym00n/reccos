# reccos

The public web profile page for reccos, served by GitHub Pages: `https://slym00n.github.io/reccos/?u=<username>` shows that person's reccos.

It's one static page (`index.html`) that reads public data with the app's public (publishable) key. The app's code is in a separate, private repo; this page is a copy of its `web/index.html`.
